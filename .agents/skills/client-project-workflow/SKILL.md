# Client Project Workflow

## Workflow
1. Requirements & Analysis
2. Sitemap & Feature List
3. Architecture Design
4. UI/UX Implementation
5. Integrations & Logic
6. Testing & Security Review
7. Client-Ready Polish & Deployment

## Best Practices
- Prioritize reliability and maintainability over shipping speed.
- Over-communicate decisions and document architecture choices for the client.

## Common Failure Modes
- Skipping the architecture phase and coding blindly, leading to rewrites.
- Forgetting the client handoff documentation.

## Verification Procedure
- Complete a final end-to-end walkthrough before delivering to the client.
