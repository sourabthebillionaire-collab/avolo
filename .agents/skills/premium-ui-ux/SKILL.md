# Premium UI/UX

## Workflow
1. Analyze the requested UI feature in the context of the site's existing visual hierarchy.
2. Draft structural HTML elements before applying styles.
3. Apply responsive, mobile-first CSS targeting distinct breakpoints.

## Best Practices
- Avoid generic "AI-generated site" tells: do not use default gradient-purple heroes, generic sans font stacks, cookie-cutter 3-column icon grids, or unstyled Bootstrap/shadcn defaults.
- Design must reflect agency/product-designer quality: use deliberate type scales, restrained color palettes, real content hierarchy, and custom iconography or spacing rhythms.
- Ensure WCAG basics (contrast, semantic tags).

## Common Failure Modes
- Treating mobile responsiveness as an afterthought.
- Clashing color palettes or inconsistent padding/margins.

## Verification Procedure
- Test layout on mobile and desktop viewports.
- Confirm interactive elements (buttons, inputs) have distinct hover, focus, and active states.
